# App File Structure

This file explains where the app's code will go.

## Main files

- `pubspec.yaml`: App details and the list of packages the app uses.
- `lib/main.dart`: Starts the app and initializes Firebase.
- `lib/app.dart`: Configures the MaterialApp, theme, and authentication gate.
- `lib/firebase_options.dart`: Firebase settings generated by FlutterFire.

## Folders inside `lib`

- `models/`: Describes app data, such as groups, members, debts, and expenses (`group.dart`).
- `screens/`: Contains full app pages (`sign_in_screen.dart`, `groups_screen.dart`).
- `services/`: Connects the app to external services (`auth_service.dart`).
- `utils/`: Contains small shared helper functions.
- `widgets/`: Contains small parts of the screen that can be reused.

## Documentation

- `docs/`: Contains notes about the app and what we learn while building it (`PROJECT_GUIDE.md`, `FILE_STRUCTURE.md`).

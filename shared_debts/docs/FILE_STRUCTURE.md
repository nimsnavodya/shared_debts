# App File Structure

This file explains where the app's code will go.

## Main files

- `pubspec.yaml`: App details and the list of packages the app uses.
- `lib/main.dart`: Starts the app.

## Folders inside `lib`

- `models/`: Describes app data, such as groups, members, debts, and expenses.
- `screens/`: Contains full app pages.
- `services/`: Connects the app to Google sign-in, cloud storage, and reminders.
- `utils/`: Contains small shared helper functions.
- `widgets/`: Contains small parts of the screen that can be reused.

## Documentation

- `docs/`: Contains notes about the app and what we learn while building it.
